**Codex OAuth 可以获取模型和检查连接，四个模型映射菜单更易读、也更易用。**

0.3.3 汇集 v0.3.2 之后的模型发现与 Provider 编辑器改进。已连接的 Codex OAuth
账号可以直接获取模型目录；获取一次后，Main / Haiku / Sonnet / Opus 共用候选
列表。连接诊断、模型选择和保存仍是独立操作，已有配置不会被自动替换。

## Codex OAuth：模型发现与连接诊断

- **启用 Fetch models。** 使用 Provider 绑定的托管账号，或跟随当前默认账号，读取
  固定的 Codex 模型目录。无需 API Key、自定义端点或运行中的本地路由；后端负责
  托管凭据与刷新。明确绑定的账号缺失时不会悄悄改用其他账号。
- **启用 Diagnostics。** **Check OAuth connection** 显示目录是否可达，并逐项标记
  模型映射为 **Listed in catalog**、**Not listed in catalog** 或 **Unset**。
  没有可用账号时提示先连接；错误信息不包含上游响应正文或凭据。
- **隔离账号结果。** 切换绑定账号或当前默认账号会清除旧目录/诊断结果，忽略旧
  请求的迟到响应。修改映射时可复用当前账号的结果，无需重新检查。

连接诊断使用独立的目录快照，不会填充选模菜单，也不会发送生成请求或保存
Provider。目录存在不保证生成权限；未列出的模型仍可手动填写。确认实际调用时，
请选择 **Route Target → Start Route**，再从 Claude Code 发起请求并查看 **Usage**。
API Key Provider 的 **Detect endpoint type** 继续用于识别协议类型。

## 模型映射与下拉菜单

- **获取一次，四个映射共用。** Fetch models 打开大列表；通过 **Apply model**
  只修改选定用途的草稿。取消大列表后，四个输入旁的箭头仍可浏览同一目录。
  **Choose model** 复用已获取列表，**Refresh models** 明确重新获取。
- **完整搜索与手动输入。** 打开映射菜单不会被当前输入值自动过滤；搜索覆盖
  全部候选，结果每次显示 100 个，可通过 **Show more** 继续展开。保留未列出的
  已配置模型与手动 ID。获取模型不自动覆盖映射，完成选择后仍需 **Save**。
- **清楚的缓存范围。** 列表属于本次打开的编辑器；关闭后重新打开，或更改连接
  信息/账号，需要重新获取。同一连接的刷新失败会保留上一次成功的列表。
- **修复可读性与对齐。** 原生下拉选项使用深色背景和清晰文字。映射菜单对齐
  输入框，按可用空间向上/下展开，避免被卡片或对话框裁切；支持搜索、键盘导航、
  Escape 关闭与焦点恢复。长模型 ID 不会撑宽页面。

使用指南、编辑器说明、排错文档和前端设计约定同步更新，覆盖组件状态归属、
账号切换、菜单交互及目录检查的能力边界。

## 升级后的页面加载恢复

修复升级后旧页面引用已被替换的懒加载文件而导致界面不可用的问题。服务器对
入口页面和缺失资源禁用缓存，对正常资源要求重新验证。页面加载失败时保留侧栏
导航，显示 **Reload interface**；不会自动刷新丢弃草稿或陷入重载循环。

已打开的旧版页面需要先手动刷新或重新打开，才能取得新版入口。网络中断也可能
导致同类错误，持续失败时检查服务与安装包中的前端目录。保存的 Provider 和
OAuth 账号不需要重建。

## 升级到 0.3.3

发布后，Linux / macOS 发布包安装可运行：

```bash
cc-switch-ui update
cc-switch-ui version
cc-switch-ui status
```

升级后刷新浏览器页面，再检查 Provider 的账号绑定和模型映射。**数据库仍为
schema 5**；从 v0.3.1/v0.3.2 升级不增加 schema 迁移。保留升级恢复副本及重要
live 配置备份，完成账号、路由和待恢复操作检查后再清理。

每个发布包包含 CLI 和 Web 前端，并附对应的 `.sha256` 文件：

| 系统 | 安装包 |
| --- | --- |
| Linux x86_64 | `cc-switch-ui-linux-x86_64.tar.gz` |
| macOS Intel | `cc-switch-ui-macos-x86_64.tar.gz` |
| macOS Apple Silicon | `cc-switch-ui-macos-aarch64.tar.gz` |
| Windows x86_64 | `cc-switch-ui-windows-x86_64.exe.zip` |

Windows 升级需停止服务后替换发布包，并保留完整用户数据。

## English highlights

Codex OAuth now supports managed model discovery and catalog connection
diagnostics without an API key or a running local route. Explicit account
bindings never fall back silently; account changes invalidate stale results.
Diagnostics reports catalog reachability and mapping presence, separately from
generation access and model-selection state.

All four model mappings share fetched choices, retain manual IDs, search the
full catalog and use aligned, keyboard-accessible menus. Native dropdown colors
are readable in the dark theme. Selection updates one draft role; saving remains
explicit. Database schema stays at 5, and upgrade CI adds published v0.3.2 to
the existing compatibility matrix.

UI entries and missing assets are not cached. Lazy-page failures preserve
navigation and offer an explicit reload, improving recovery when an upgrade
replaces old chunks or a network request fails.
