**为自定义模型显式设置上下文窗口，并加强路由中断后的配置恢复验证。**

## 自定义模型上下文窗口

在 **Providers → Edit provider → Advanced → Context window (tokens)** 中填写
网关确认的 token 上限，点击 **Preview save** 检查后再 **Save**，然后重启
Claude Code。例如，网关明确支持一百万 tokens 时可填写 `1000000`。

- 保留 Provider 或预设中已有的窗口值；留空不新增覆盖，清空字段只移除该
  Provider 的窗口覆盖。
- 输入必须是正整数。不会根据模型名称或 Fetch models 的目录结果推断容量。
- 修改窗口不会改写模型 ID、四个角色映射、`modelPicker` / `behavesAs`、
  `modelOverrides` 或已有自动压缩设置。获取模型、预览与保存仍是独立操作。
- 多个映射的可用窗口不同时，采用适用模型中最小的已确认限制。

该设置用于 Claude Code 的客户端窗口计算，不会扩大上游实际容量，也不会保证
消除所有模型目录警告。已知 Claude 模型、`behavesAs` 和本地路由的 Claude 别名
遵循各自的窗口规则，详见 [编辑器说明](https://github.com/huangbogeng/cc-switch-ui/blob/v0.3.4/docs/provider-editor.md#custom-model-context-windows)。

## 配置恢复与回归检查

保留已有的官方订阅免密编辑、用户设置保护和持久化接管快照实现。本次加强真实
CLI / HTTP 流程测试：路由运行中修改兼容开关，再终止并重启服务，确认停止路由
后移除未修改的接管窗口和自动模式字段，同时保留用户修改及全局设置。

升级 CI 新增从已发布 **v0.3.3** 升级与回滚的路径，保留 v0.1.9、v0.2.0、
v0.3.1、v0.3.2 的检查。测试使用隔离 profile、合成凭据和本地模拟服务；不代表
所有真实上游模型均已验证。macOS / Windows 发布包由 CI 构建。

## 升级到 0.3.4

Linux / macOS 发布包安装可运行：

```bash
cc-switch-ui update
cc-switch-ui version
cc-switch-ui status
```

升级后刷新浏览器页面。**数据库仍为 schema 5**，不新增迁移，已有 Provider、
模型映射和 OAuth 绑定继续保留。升级前备份完整 profile 和重要 live 配置；
若路由之前被中断，先恢复直连配置，再重新启动路由。Windows 请停止服务后
替换完整发布包。四个平台的发布包均附对应 `.sha256` 文件。

## English highlights

Providers can declare a confirmed custom-model context window under Advanced.
The optional positive token count uses the existing preview/save flow and keeps
model identity, picker profiles and compaction settings unchanged. Restart Claude
Code after saving. Known Claude IDs and local-route aliases have separate rules.

Recovery regressions now explicitly check route-owned window cleanup and the
preservation of user-edited compatibility settings across process termination.
Linux upgrade/rollback CI adds published v0.3.3. Database schema remains at 5.
