**更清晰的 Skills / MCP 管理，更可靠的失败重试与操作恢复。**

0.3.1 在 0.3.0 的基础上完善日常操作体验：先选择要导入的项目，默认启用并应用新增项；移除的项目会被记住，重启或再次导入不会悄悄把它们带回来。各页面也能更明确地区分加载失败、空列表和部分完成的操作。

## Skills 与 MCP：导入、启停和恢复

- **先预览，再导入。** Import 打开只读扫描窗口，展示候选项目及来源，支持搜索和逐项选择；取消不会更改记录或文件。大列表分批展示，单次最多选择 2,000 项。
- **新增项默认立即生效。** `Import and enable` 默认勾选，仅应用本次新导入的项目，保留已有项目的启用状态和未管理的配置。取消勾选则只保存记录，之后使用 Sync 应用。
- **移除决定会被记住。** Remove 清理被管理的 Claude Code 配置或 Skills 副本，并保留移除记录；普通 Import 和 Sync 不会自动恢复它们。通过 `Recovery → Restore removed` 可明确恢复为禁用状态，再按需启用。
- **更直观的开关。** Skills 和 MCP 使用支持键盘操作的滑动开关；Skills 集合可一次启用或禁用整个分组。搜索时明确显示 `Entire group`，提醒操作也包含隐藏成员。
- **部分失败可以继续处理。** Import / Sync 的成功、跳过和错误结果统一显示在浮动通知中，详情可展开、滚动和关闭。应用失败会保留已保存的记录，并提示通过 Sync 重试；导入请求失败时保留窗口和选择。

Skills 插件原件仍由原插件管理。此处的启停和移除针对 CC Switch UI 管理的 Claude Code Skills 副本。未完成的删除清理继续显示在 Deletion recovery 中，需要先处理才能进行后续写入。

## 日常页面：失败可见，状态可恢复

- **Providers**：读取失败时显示不可用状态和 Retry；删除、停止路由或恢复操作丢失响应后重新读取状态，呈现已提交的变化和待恢复操作。
- **Settings**：配置读取成功后才开放保存，避免把回退默认值误写入；空端口和 `0` 会进入明确校验，保存期间锁定字段，继续编辑后清除 Saved 标记。
- **OAuth**：分别重试 ChatGPT / Copilot 账号读取，不再把未知状态显示成未连接；设默认账号和移除账号丢失响应后刷新实际状态。
- **Dashboard / Usage**：增加刷新与失败重试；活动和请求日志读取失败不再表现为空数据。会话同步显示导入、跳过和部分错误详情，窄屏用量标签保持可横向滚动。

## 升级到 0.3.1

Linux / macOS 的发布包安装可直接运行：

```bash
cc-switch-ui update
cc-switch-ui version
cc-switch-ui status
```

没有 `update` 命令的旧版可先使用安装脚本：

```bash
curl -fsSL https://raw.githubusercontent.com/huangbogeng/cc-switch-ui/v0.3.1/install.sh | bash
```

升级前保留完整 `~/.cc-switch` 数据目录，并单独备份重要的 Claude Code 配置。此版本会将数据库升级到 **schema 5**，迁移前自动保存原数据库快照。移除历史从新版本中的移除操作开始记录，无法推断升级前已经移除的项目。需要退回旧版时，恢复对应的升级前程序和数据副本；不要让旧程序直接读取迁移后的数据库。

升级后检查 Providers、OAuth、Skills、MCP 和待恢复操作，再按需启动本地路由。随机生成的 Admin Token 可能随重启变化，请使用新启动日志中的 token。

## English highlights

This patch improves Skills/MCP management and recovery across the web console. Read-only discovery lets you select imports; **Import and enable** applies only newly imported items by default. Remembered removals survive restarts, while explicit restoration returns records disabled. Accessible switches, collection controls, floating batch reports, and retained selections make failed operations easier to retry.

Providers, Settings, OAuth, Dashboard, and Usage now expose read failures and retry controls more clearly. Lost mutation responses refresh observed state. Linux/macOS release installations can upgrade with `cc-switch-ui update`; Windows uses manual replacement. Database schema 5 is backed up before migration.
